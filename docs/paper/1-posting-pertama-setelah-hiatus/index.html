Di Hugo, ketika ingin membuat postingan. Kita perlu melakukan perintah $ hugo new content content/nama-direktori-postingan/nama-postingan.md. Kemudian kita perlu mengisi file tersebut dengan konten yang ingin kita publikasikan. Formatnya akan seperti ini:

3

+++
date = "2025-09-20T03:22:55+07:00"
draft = false
title = "Nama Postingan"

Hal tersebut merepotkan dan redudant, Mengapa tidak membuat sebuah script sederhana agar tidak perlu melakukan perintah tersebut?

Karena saya berada pada lingkungan Windows, mari buat sebuah scripting PowerShell dengan nama new.ps1:

$d = "content/paper"
$max = (Get-ChildItem $d -Directory | Where-Object { $_.Name -match '^\d+-' } | ForEach-Object { [int]($_.Name -replace '-.*$', '') } | Measure-Object -Maximum).Maximum
if (-not $max) { $max = 0 }
$n = $max + 1
$t = Read-Host "Masukkan judul post"
$slug = $t.ToLower() -replace '[^\w\s]', '' -replace '\s+', '-'
$target = "$d/$n-$slug"
hugo new "$target/index.md"
$filePath = "$target/index.md"
if (Test-Path $filePath) {
    (Get-Content $filePath) -replace "title = '.*'", "title = '$t'" | Set-Content $filePath
}
Set-Location $target

Penjelasan detail baris per barisnya begini:

  1. $d = "content/paper": Mendefinisikan variabel $d sebagai path direktori tempat konten (paper) akan disimpan.
  2. $max = (Get-ChildItem $d -Directory | Where-Object { $_.Name -match '^\d+-' } | ForEach-Object { [int]($_.Name -replace '-.*$', '') } | Measure-Object -Maximum).Maximum: Baris ini berfungsi untuk menemukan nomor urut terbesar dari folder yang sudah ada.
    • Get-ChildItem $d -Directory: Mengambil semua folder dalam direktori content/paper.
    • Where-Object { $_.Name -match '^\d+-' }: Memfilter hanya folder yang namanya diawali dengan angka diikuti tanda hubung (misalnya 1-judul, 2-judul).
    • ForEach-Object { [int]($_.Name -replace '-.*$', '') }: Mengubah nama folder tersebut menjadi angka (misalnya 1-judul menjadi 1).
    • Measure-Object -Maximum: Menghitung nilai maksimum dari angka-angka tersebut.
  3. if (-not $max) { $max = 0 }: Jika tidak ada folder yang ditemukan (misalnya saat pertama kali membuat), maka $max di-set ke 0.
  4. $n = $max + 1: Menentukan nomor urut baru (nomor berikutnya).
  5. $t = Read-Host "Masukkan judul post": Menampilkan prompt kepada pengguna untuk memasukkan judul postingan baru.
  6. $slug = $t.ToLower() -replace '[^\w\s]', '' -replace '\s+', '-': Mengubah judul menjadi format ‘slug’ (slug) (huruf kecil, tanpa spasi atau karakter khusus, diganti strip -).
  7. $target = "$d/$n-$slug": Menggabungkan direktori utama, nomor urut, dan slug menjadi path lengkap tujuan.
  8. hugo new "$target/index.md": Membuat file baru di path yang sudah ditentukan menggunakan template Hugo.
  9. $filePath = "$target/index.md": Menyimpan path file yang baru dibuat ke variabel $filePath.
  10. if (Test-Path $filePath) { (Get-Content $filePath) -replace "title = '.*'", "title = '$t'" | Set-Content $filePath }: Jika file berhasil dibuat, skrip ini mencari baris title = '...' di dalam file tersebut dan menggantinya dengan judul yang baru saja dimasukkan.
  11. Set-Location $target: Mengarahkan terminal (PowerShell) agar berada di dalam direktori postingan yang baru dibuat, sehingga pengguna bisa langsung mulai mengetik konten.
